# 造物 Atelier

造物 Atelier 是一款面向 AI 图像与视频创作的节点式画布软件。它把常用的图像生成、图像编辑、视频处理和工作流调用整理成可视化节点，让用户可以在同一个画布里组织素材、连接处理结果，并完成多步骤创作。

当前版本：`0.2.3`

作者：空杯心

联系方式：`starrylover8`

## 软件介绍

造物 Atelier 的核心是画布工作区。用户可以在画布中添加图像节点、视频节点和不同类型的 AI 工作流节点，通过节点之间的结果传递完成创作流程。

适合的使用场景包括：

- AI 图像生成与二次处理
- 视频素材处理与结果预览
- 人像、背景、遮罩等创作流程整理
- 多个生成步骤之间的素材管理
- 将常用工作流封装成更直观的节点操作
