# 造物 Atelier

**面向内容创作的多模态 AI 智能体平台。**

造物 Atelier 将不同创作任务拆分为独立智能体，并通过统一的账户、资产、任务与点数体系协同工作。当前已开放 **无限画布** 与 **口播智能体**，后续将继续加入更多轻量创作应用。

- 当前版本：`0.3.1`
- 支持系统：Windows 10 / 11 64 位
- 运营方：SA智能应用研究室
- 官方网站：[atelier.aikong.top](https://atelier.aikong.top)

## 当前功能

### 无限画布

使用可自由连接的节点组织图像、视频、文本、音频和 AI 工作流，在同一画布中完成素材引用、生成、编辑、批量循环与结果管理。

### 口播智能体

覆盖口播内容从策划到发布的主要流程：

- IP 军师：对标账号分析、爆款视频提取、行业选题、文案生成与 AI 法务
- 音视频合成：音色资产、数字形象、声音克隆、视频克隆与多语言生成
- 视频编辑：字幕、关键词高亮、背景音乐、画中画与多轨时间轴
- 智能发布：封面设计、标题与话题标签、平台账号管理及多平台发布
